## Hot List Observations

**Category distribution today** skews heavily toward **AI Applications** and **AI Infrastructure**. Coding agent tooling (design.md, gstack, opencode, claude-howto) accounts for six of the top AI trending repositories, reflecting a community keen on standardizing and supercharging how agents work with codebases. AI memory and RAG infrastructure (cognee, mem0, ragflow) continue to see strong activity, though cognee is the only RAG-related project in today’s trending top 20. **AI Agents** are well represented through projects like opencode and hermes-agent, but the standout is the financial agent category – ai-berkshire and Vibe-Trading both appear in trending, and TradingAgents is among the most-starred topic search results. **LLM training** is almost absent from trending today, with focus instead on using existing models via agents and apps.

**New or unusual project types**: `design.md` is a novel format – a spec for visual identity intended for agent consumption, not human designers. Similarly, `OpenSpec` pushes spec-driven development for AI assistants. The `ai-website-cloner-template` shows a rising pattern of “one-command cloning” via agents. The appearance of multiple Claude Code–centric toolkits (gstack, claude-howto) suggests Claude Code is becoming a preferred agent harness for tool builders.

No direct connection to specific LLM releases is evident from today’s data, but the prevalence of agent-oriented projects aligns with the broader industry direction toward autonomous coding and multimodal generation.
