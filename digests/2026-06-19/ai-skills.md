### 2. 社区需求归类

从 Issues 中，社区反映的需求可归类为以下几个方向：

- **工具链可靠性**: 这是最强烈的信号。多个 Issue (#556, #1169, #1061, #202) 指出 `skill-creator` 工具在评估、兼容性和文档指导性上存在严重问题，阻碍了有效的技能开发和优化。
- **分发与协作**: 社区不仅需要创建技能，还需要更便捷的**共享和管理机制**。具体需求包括组织级共享 (#228)、防止命名空间混淆 (#492) 以及解决因插件重复安装导致的上下文空间浪费 (#189)。
- **集成与兼容性**: 用户希望 Skills 能与更广泛的外部系统和平台集成，如 AWS Bedrock (#29) 和 MCP 协议 (#16)。同时，**Windows 兼容性**是多个 Issue 和 PR 反复提及的具体痛点 (#1061)。
- **新技能方向**:
    - **Agent 治理**: 提案 #412 提出了“agent-governance”技能，关注 AI Agent 系统的安全模式、策略执行和审计跟踪。
    - **紧凑数据格式**: 提案 #1329 提出“compact-memory”技能，主张使用符号标记来压缩长期运行 Agent 的记忆和状态，以节省上下文窗口。
    - **专注特定平台**: 提案 #568 提出了针对 ServiceNow 平台的全面技能套件，覆盖其多个模块。
