## 1. 本周要闻

- **Anthropic 发布 Claude Opus 5，性价比颠覆 Max 订阅**（7/27）
  Opus 5 性能接近 Fable 5 但价格减半，即日起成为 Claude Max 默认模型。但上线当日出现服务错误率升高，状态页事件引发 HN 91 分讨论，口碑与稳定性形成反差。

- **OpenAI Codex 静默缩减上下文窗口，引发社区强烈反弹**（7/20）
  PR #33972 将模型上下文窗口从 372k 显式缩减至 272k，HN 讨论达 327 分，用户普遍认为这是“降级不通知”的失信行为，加剧对模型可靠性的担忧。

- **OpenClaw v2026.7.1 正式版触发大规模启动崩溃**（7/16）
  至少 5 个独立 P0 报告，根因是遗留状态迁移逻辑导致网关启动致命错误，`openclaw doctor` 无法修复。同日紧急发布 beta.1 尝试补救，但修复方案未锁定，成为本周 Agent 生态最严重事故。

- **Claude Code 切换至 Rust 版 Bun，成为 HN 最高热帖**（7/20）
  该架构迁移获 404 分、566 评论，Simon Willison 发文解析。但 Windows 平台随之出现图片附件静默退出、Cowork 不可用等新兼容性问题。

- **OpenAI 推出“Health in ChatGPT”与 GPT-Red 红队系统**（7/27 / 7/16）
  前者允许美国用户连接医疗记录与 Apple Health 获取个性化洞察；后者采用自对弈机制提升模型安全性与提示注入鲁棒性。显示 OpenAI 向垂直行业与安全基础设施双向延伸。

- **陶哲轩用 ChatGPT 探讨雅可比猜想反例，AI 数学推理再引激辩**（7/23）
  完整对话公开，679 分、404 评论，社区对 AI 在高级数学推理中的表现分歧明显，部分研究者认为仍属模式匹配，另一些则看到推理突破。

- **Skills 生态爆发信任危机：命名空间冒充与评测工具失效**（持续整周）
  anthropics/skills 仓库 #492（社区技能伪装官方命名空间）讨论达 34 评论；#556 评估脚本 `run_eval.py` 触发率 0%，两个修复 PR 待合并。技能生态的可信基础与开发者工具链同时暴露短板。

## 2. CLI 工具进展

**Claude Code**
本周发布节奏密集：v2.1.211（7/16）修复子代理输出与 Unicode 安全；v2.1.214（7/19）紧急修复 Windows BSOD 与 PowerShell 权限绕过；v2.1.218（7/23）改进后台 `/code-review` 与屏幕阅读器。7/27 无新版本，但 Issue 更新 50 条，PR 7 条。跨平台兼容性仍是主要痛点：Windows 原生 exe 挂起、TUI 请求思考过程（+324👍）、用量瞬间耗尽等高频反馈。7/27 发现硬编码禁止 Opus 5 使用子代理，HN 讨论 25 分。

**OpenAI Codex**
Rust 后端迭代极快，7/20 一天推送 4 个 alpha 版本，7/23 合入 10+ 个 PR。但上下文缩减事件（7/20）严重打击用户信任，60 秒自动回答（#28969，151👍）也引发强烈不满。Windows 桌面端冻屏、沙盒 `apply_patch` 失败、MCP 内存泄漏超 9GB 等稳定性问题持续未解。

**Kimi Code**
密集修复为主：v0.24.2（7/16）通过 50 PR 修复 CLI 静默退出与认证绕过；v0.26.0（7/17）解决 Windows ANSI 转义序列；v0.27.0（7/18）新增剪切板命令与 worktree 隔离；v0.29.0（7/23）率先在 ACP 客户端支持思考深度选择。PR 活跃度多次超过 Issue，响应速度领先。

**OpenCode**
v1.18.2（7/16）默认禁止子代理嵌套并修复上下文溢出；v1.18.3（7/17）桌面补丁。内存泄漏帖（#20695）累计 110 评论，Windows ARM64 启动失败、TUI 粘贴失效等平台问题突出。7/27 社区关注子代理交互限制：无法直接通信（#38964）与无法向父代理提问（#38963），多代理协作的交互隔离成为共同短板。
