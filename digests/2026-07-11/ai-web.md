  - **分类**：Tiered Cache / 产品更新
  - **发布日期**：2026-07-10
  - **链接**：https://blog.cloudflare.com/smart-tiered-cache-for-public-clouds/
  - **内容提炼**：Cloudflare 对 Smart Tiered Cache（智能分层缓存）做出架构增强，推出“Smart Tiered Cache for Public Cloud Regions”。问题背景：当源站部署在公有云并使用 Anycast 或区域 Unicast 前端时，单个源 IP 对多个 Cloudflare 数据中心延迟表现接近，原有的基于延迟自动选择单一最优上层数据中心（upper-tier）的算法会失效，回退至多个上层节点，导致缓存效率下降。本次更新允许用户提供一个云区域提示（cloud region hint），Cloudflare 据此能将公有云源站映射到正确地域，并选择更优的主上层和备用上层节点。该功能面向所有套餐免费提供。文章同时回顾了该系列的延续性增强：2024 年 11 月已为 R2 对象存储引入智能分层缓存支持；本次更新将该智能选择能力延伸至通用公有云源架构。
