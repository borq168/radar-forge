## 热榜观察

1. **Agent 工具层密集出现**：今日 Trending 中 **6 个 Agent 相关项目**（flue、superpowers、GLM-5、agent-native、headroom、codebase-memory-mcp）都有明确新增 stars，其中 headroom 和 codebase-memory-mcp 均提供 MCP 服务器接口，表明开发者社区正在主动构建 Agent 的“基础设施层”。
2. **token 压缩成为新热点**：headroom 单日 4005 stars，远超其他项目，反映 **LLM 成本敏感型用户** 对减少 token 消耗的强需求。同一趋势也体现在 codebase-memory-mcp（通过知识图减少重复索引 token）上。
3. **时间序列基础模型入局**：TimesFM 是本周唯一全新基础模型发布，最高 +1510 stars，标志 **AI 基础模型从文本/视觉扩展到时间序列**。
4. **MCP 协议被广泛采纳**：headroom、codebase-memory-mcp 均显式支持 MCP 协议，结合主题搜索中多个项目（如 claude-mem、CowAgent）已集成 MCP，MCP 正成为 Agent 工具接口的事实选项。
5. **视频生成领域出现 Agent 化尝试**：OpenMontage 和 LTX-2 分别从“Agent 控制管线”和“本地推理训练”切入，与 palmier-pro（macOS 编辑器）共同构成今日视频 AI 的三条不同路径。
