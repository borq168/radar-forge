## 一、本周要闻

1. **Anthropic 发布「双子星」模型，旋即遭政府限令**（06-10 / 06-13）
   Anthropic 推出 Claude Fable 5 和移除部分安全限制的 Mythos 5；三日后美国政府依据国家安全权限要求立即切断 Fable 5 和 Mythos 5 对外国国民的访问。社区围绕地缘政治、模型管制和开源必要性展开激烈讨论。

2. **OpenAI 秘密提交 S-1 上市申请，同时考虑大幅降价**（06-09 / 06-12）
   OpenAI 向 SEC 秘密提交 IPO 文件，并据华尔街日报报道正研究降价策略以应对 Anthropic 竞争。这一动向引发社区对非营利转营利、安全承诺和估值风险的广泛辩论。

3. **NVIDIA SkillSpector 登顶 GitHub 热榜**（06-15）
   单日 +964 stars 的 AI 智能体技能安全扫描器成为本周最受关注的开源项目。同期 `agent-skills`、`superpowers`、`last30days-skill` 等技能框架项目持续冲榜，Agent 技能生态进入爆发期。

4. **CLI 工具成本失控与稳定性危机集中爆发**（整周）
   Claude Code 子代理无成本上限导致千美元意外费用（#68285），Codex 桌面版闪退（#27979 等多条），OpenCode 子代理行为失控，Windows 平台兼容性问题被多个工具社区同时投诉。

5. **Skills 生态评估工具链持续失效**（整周）
   `run_eval.py` 在全部平台上报 0% 召回率（#556、#1169、#1298），直接阻断贡献者本地验证流程。该问题已持续三个月，成为当前生态效率最大堵点。

6. **OpenClaw 密集安全更新，P0 级 Bug 仍待解**（06-09 ~ 06-15）
   OpenClaw 一周内发布 7 个 beta 版本，收紧 transcripts、sandbox、MCP stdio 等 12 项安全边界。但 Gateway 内存泄漏至 15GB+（#91588）、子任务静默丢失（#44925）、工具调用文本泄漏到消息频道（#25592）等 P0/P1 级 Bug 仍未完全修复。

7. **里约热内卢「自研」LLM 被社区揭穿**（06-15）
   里约市政府宣称自主研发的 LLM 被开发者发现仅是对现有模型（如 LLaMA）的合并与微调，引发 290 分 HN 讨论，开源透明度问题再度成为焦点。

8. **Anthropic 与 TCS、DXC 建立企业联盟**（06-12 / 06-13）
   Anthropic 分别与 IT 服务巨头 TCS 和 DXC 签署多年合作协议，重点将 Claude 引入金融、医疗等受监管行业；同时宣布投入 1.5 亿美元启动「Claude Corps」国家奖学金计划。

**跨工具共性挑战**：
- **子代理成本与行为失控**：多工具出现无限递归、Token 耗尽、外部脚本自主调用。
- **MCP 协议兼容性**：6 个工具社区同时反映 MCP 集成不完整、不稳定或难以发现。
- **Windows 平台短板**：WSL 性能慢、OAuth 失败、VM 崩溃、路径编码问题等。
- **模型可见性/选择权**：用户抱怨无法指定底层模型，或模型被静默降级。
