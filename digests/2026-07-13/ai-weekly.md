   所有工具结果返回 `(see attached image)` 占位符（#104721），与 OpenCode #99241 相同症状，暴露跨项目渲染管道缺陷。

   核心评估脚本完全失效，#556 被多人复现，多个竞争性 PR 等待合并，动摇了技能生态的可信度。

6. **Claude Code 连续发布修复版本**（7/8-7/12）
   v2.1.203→v2.1.207 共 5 个版本，主要修复终端冻结、会话压缩丢失消息等稳定性问题，但 Token 用量激增 (#41506) 成为社区最大痛点。

7. **Kimi Code 社区代码贡献量反超**（7/11-7/13）
   两日合并 16 个 PR（agent-core-v2 引擎落地、OAuth 登录等），在 CLI 赛道中表现突出。

8. **GPT-5.6 宣称证明数学猜想引激烈辩论**（7/11）
   Sol Ultra 称完成 Cycle Double Cover 猜想证明，社区从数学严谨性到模型幻觉展开多轮攻防 (313 分, 258 评论)。

## CLI 工具进展

**Claude Code**
- 本周发布 v2.1.203、v2.1.204、v2.1.205、v2.1.207 共 4 个版本，侧重会话稳定性与 UI 冻结修复。
- 痛点集中：Token 用量透明度（#41506 消耗异常、#38029 resume 额外消耗），复合命令权限拆分需求 (#16561 获 173 赞)。
- Windows 兼容性短板持续：沙箱崩溃 (#76094)、快捷方式残留 (#76980) 未解决。
- 大上下文下 Advisor 工具不可用 (#67609)，会话压缩丢失用户最后一条消息 (#50724)。

**OpenAI Codex**
- 发布 v0.143.0、v0.144.0→v0.144.1 紧急修复、多个 alpha 预发行；Rust CLI 加速迭代。
- GPT-5.6 Sol/Luna 多代理行为强制启用，用户无法指定子代理模型 (#31814、#31097)，可控性担忧强烈。
- GPT-5.5 token 暴涨 10–20 倍 (#28879) 达 204 评论 354 赞，成本问题尖锐。
- 长期诉求：Linux 桌面应用（733 赞）、SQLite 年写入 ~640 TB 对 SSD 耐久性的影响。

**Kimi Code**
- 发布 v0.23.4、v0.23.6 补丁，修复 Git Bash 检测、goal 状态丢失等，i18n 与 agent-core-v2 引擎快速落地。
- 社区提交量居 CLI 之首：7/11 单日 16 个合并 PR，反映生态活跃度提升。

**OpenCode**
- v1.17.17、v1.17.18 及修复版发布，解决剪贴板、定价崩溃、LSP 容器化等问题。
- 工具调用死循环 (#3743)、数据库膨胀至 13GB (#33356) 存长期隐患；工具输出误渲染为图片占位符 (#99241) 与 OpenClaw 同源。

**Gemini CLI & Qwen Code**
- Gemini CLI v0.50.0 + v0.51.0 预览，安全加固（RCE/SSRF/OAuth）与渲染体验提升。
- Qwen Code 一周 3 个版本 + 大量 PR，daemon 多工作区与通道集成快速迭代。
