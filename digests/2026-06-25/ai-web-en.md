### 2. Per-Source Highlights

#### Anthropic
**Article: [Introducing Claude Tag](https://www.anthropic.com/news/introducing-claude-tag)**
- Category: News | Published: 2026-06-23
Claude Tag introduces a new paradigm for team-AI collaboration, starting with Slack integration. Claude can be added to selected Slack channels as a team member, with access to chosen tools, data, and codebases. Users can tag @Claude to delegate tasks — including code creation, data retrieval, support ticket triage, and bug root cause analysis — while Claude builds context from channel history and can plan future tasks. Anthropic reports that 65% of its product team’s code is now generated by an internal version of Claude Tag. The feature is available in beta for Claude Enterprise and Team customers, with plans to expand to other platforms.

#### OpenAI
**Article: [OpenAI and Broadcom unveil LLM-optimized inference chip](https://openai.com/index/openai-broadcom-jalapeno-inference-chip)**
- Category: Company | Published: 2026-06-24
OpenAI and Broadcom introduced **Jalapeño**, a custom-built AI chip tailored for LLM inference workloads. The chip aims to improve performance, energy efficiency, and scalability across OpenAI’s inference systems. While no architectural specifics or performance benchmarks are provided in the excerpt, the announcement signals a strategic move toward custom silicon for serving large models at scale, reducing reliance on general-purpose hardware.

#### Cloudflare Blog
**Article: [Unlocking the Cloudflare app ecosystem with OAuth for all](https://blog.cloudflare.com/oauth-for-all/)**
- Category: Developers | Published: 2026-06-24
Cloudflare announced that **self-managed OAuth** is now available to all developers on its platform. Previously, third-party OAuth was limited to a small number of manually onboarded integrations; developers had to rely on API tokens for delegated access. The new system allows any developer to create OAuth clients with scoped permissions, making it easier to build SaaS integrations, CI/CD pipelines, and integrations with agentic tools. Cloudflare notes that the move was driven by growth in its Developer Platform and increasing demand from agentic workflows for scoped, delegated access to Cloudflare APIs.
