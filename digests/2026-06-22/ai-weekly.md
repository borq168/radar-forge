## 2. CLI 工具进展

### Claude Code
- **版本**：v2.1.179 → v2.1.181 → v2.1.183 → v2.1.185，迭代密集。
- **核心问题**：规则继承丢失（#19471）、子代理无限递归（#68619）、Linux API 无响应（#69358）、会话静默清理（#59248）。
- **正向改进**：新增 `/config` 命令、macOS 沙箱支持、安全更新。
- **社区情绪**：功能迭代积极，但回归 Bug 频繁，稳定性信心受挫。

### OpenAI Codex
- **版本**：Rust 预发布版密集发布（v0.141.0-alpha.x → 正式版 v0.141.0），重点改进远程执行加密与跨平台兼容。
- **关键事件**：Desktop 版核心功能瘫痪（`sandboxPolicy` 缺失）、Plus 用户 Token 成本飙升 10-20 倍（#28879）。
- **架构变化**：引入传输无关 Session 运行时、插件安装系统重构，为后续 Automations 做准备。

### Gemini CLI
- **版本**：v0.47.0 正式版，增加平台感知 Shell 指导。
- **主要问题**：Agent 挂起（#21409）、子代理误报成功（#22323），MCP Web Fetch 工具 SSRF 漏洞修复。
- **趋势**：安全与行为可靠性仍是最大短板。

### GitHub Copilot CLI
- **版本**：v1.0.64 系列，新增 `/diagnose` 命令、MCP 注册表安装支持。
- **问题**：子代理无法访问 MCP 工具（#3812）、WSL 下性能回归（#3700）、Windows ARM 崩溃（#3687）。
- **特点**：绑定 GitHub 生态，MCP 插件平台刚上线即遇可用性 Bug。

### Qwen Code
- **版本**：v0.18.3 → v0.18.5 正式版，修复工具重复调用、CLI 渲染等核心问题。
- **活跃度**：PR 数量全周最高，社区贡献活跃。
- **争议点**：OAuth 免费策略调整引发 136 条评论；tmux 触控板滚动异常等跨平台问题仍在修复中。

### Kimi Code CLI
- **活跃度**：最低，仅 “MCP 删除后 400 错误” (#2457) 一个热点。
- **亮点**：修复 `--continue` 找不到历史会话问题。

### 共性趋势
- **MCP 稳定性**：子进程无限制扇出、OAuth 认证冲突、Schema 兼容性等问题在多个工具中同时爆发。
- **跨平台兼容**：Windows / WSL / tmux 下的路径、编码、滚动、性能问题集中暴露。
- **成本与用量透明**：Codex 定价突涨、Claude Code 子代理 Token 爆炸，开发者对成本的敏感度达到新高。

## 3. AI Agent 生态

**OpenClaw** 是全周最活跃的 Agent 项目，几乎每天都有新版本（v2026.6.8 → v2026.6.9 → v2026.6.10-beta.1），但稳定性问题贯穿全周：

- **P0 内存泄漏**（#91588）：RSS 从 350MB 暴涨至 15.5GB，影响所有部署用户，截至周末仍无最终修复。
- **Cron 任务迁移错误**（#90378）：投递错误、隔离 Cron 始终失败。
- **会话写锁超时**（#86538）：造成消息阻塞，尤其影响 Telegram/Discord 渠道。
- **编码 Agent 回归**（#62505）：2026.4.2 版本后停止工作，仅返回模糊状态。
- **子代理完成丢失**（#44925）：团队模式可靠性不足。

**社区关键讨论**：
- **核心架构**：Issue #88838（31 条评论）讨论是否将核心 Session 状态迁移至 SQLite，反映社区对数据持久化的迫切需求。
- **跨平台客户端**：Issue #75（109 条评论）要求 Linux/Windows/Android 原生客户端，为项目历史最热需求。
- **维护瓶颈**：全周累计 500+ 活跃 Issue/PR，但合并速度远落后于提交速度，社区出现“维护者不足”的担忧。

**同赛道项目**：`agent-reach`（零 API 费搜索社交平台）和 `superpowers`（Agent 技能框架）在 GitHub 上持续受关注，反映了 Agent 与外部世界交互需求旺盛。

## 4. 开源趋势

本周 GitHub AI 热榜呈现三大技术方向：

### 🔥 Token 压缩与成本优化
- **`headroom`**（★7 天增量超 1.2 万）：LLM 输入压缩库，可压缩 60-95%，支持库/代理/MCP 三种方式，成为本周增长最快的 AI 项目。
- **`deer-flow`**（★72k，周增量稳定）：长时程 Agent 的上下文压缩与记忆管理方案。

### 🧠 代码智能与 MCP 生态
- **`codebase-memory-mcp`**（周增量 ~4600 Stars）：C 语言单二进制，零依赖，将代码库索引为持久化知识图谱，毫秒级响应，支持 158 种语言。
- **`kilocode`**（TypeScript，一体化编码 Agent 平台）、**`mattpocock/skills`**（工程师技能集直接复用）反映了“Agent 可复用技能”需求。

### 🛡️ Agent 安全与治理
- **`SkillSpector`**（NVIDIA 出品，AI Agent 技能安全扫描）、**`AutoJack` 漏洞曝光**（单个网页导致 Agent 宿主机 RCE）——社区对 Agent 安全焦虑达到新高度。
- **`Apertus`**（开源主权模型，HN 152 分）和 **`Recall`**（本地化 Claude 项目记忆工具）体现开发者对“去中心化/可掌控”方案的偏好。

### 其他亮点
- **时间序列基础模型**：Google Research 发布 `timesfm`（+1510 Stars）。
- **金融领域大模型**：`Kronos` 首次登上 Trending。
- **视频编辑**：`palmier-pro`（macOS AI 视频编辑器）成为新晋热门。
